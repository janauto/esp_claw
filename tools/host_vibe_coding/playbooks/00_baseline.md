脚本运行在单片机上的一个 Lua job 里：内存有限、没有协程调度器、没有文件系统之外的持久化。

1. **只用下面 API 参考里出现过的函数。** 参考里找不到的就是不存在，不要凭记忆或类比其他 Lua 生态猜。宁可用已有 API 绕一圈实现，也不要调一个不存在的函数。
2. **`require` 只用规划里列出的模块。**
3. **`display` 和 `lvgl` 不能在同一个脚本里混用。** 二者各自持有屏幕会话，同时用会冲突。
4. **凡是获取到句柄或初始化了会话，都要用 `pcall` 保证释放路径。** 脚本异常退出而没释放屏幕会话，会导致后续脚本都跑不起来。
5. **不要立刻结束。** 上屏内容需要停留时间，采集类脚本需要采够样本。脚本瞬间结束等于用户什么都没看到。
6. **打印足够的日志。** 关键状态变化和最终结果都要 `print`，这是上位机判断脚本是否真的成功的唯一依据。
7. 输出只包含一个 `lua` 代码块，不要写解释文字、不要分多块、不要在代码块外补充说明。
