# 快速参考：上位机优化

## 主要改进

✅ **停止响应时间**：90秒 → **2-3秒**  
✅ **轮询间隔**：2.5秒 → **1秒**（更流畅）  
✅ **默认超时**：90秒 → **15秒**（GUI）/ 30秒（CLI）  
✅ **设备端等待**：3秒 → **1.5秒**  

## 使用 GUI

### 执行短脚本（测试、查询）
- 保持默认：等待 **15 秒**
- 通常 1-5 秒完成

### 执行长脚本（游戏、动画）
- 手动调大"等待执行结果秒数"到 **60-120 秒**
- 或不等待完成，直接点"停止 job"

### 停止 Job
- 点击"停止 job" → **2-3 秒**得到反馈
- 脚本正常停止显示 "stopped"
- 无响应脚本显示当前状态

## Lua 脚本建议

```lua
-- ✅ 推荐：可快速停止
while true do
    -- 业务逻辑...
    lvgl.process_events(16)  -- 或 delay.ms(100)
end

-- ❌ 避免：无法停止
while true do
    -- 纯计算，无让出...
end
```

## 故障排查

**问题**：停止后仍显示 "running"  
**原因**：脚本无 `lvgl.process_events()` 调用  
**解决**：等待 1.5 秒设备端超时强制终止

**问题**：执行脚本感觉卡  
**检查**：日志区是否有每秒更新  
**解决**：断开重连设备
