# 移动端快速参考

## 主要改进

✅ **停止响应时间**：90秒 → **2-3秒** (30倍提升)  
✅ **轮询间隔**：2.5秒 → **1秒** (响应更流畅)  
✅ **默认超时**：90秒 → **30秒** (避免卡顿)  
✅ **新功能**：打开示例脚本 (贪吃蛇、跳跃游戏、消消乐)

## 使用示例

### 快速体验

```
1. 连接设备（设备标签页）
2. 打开示例（Lua标签页 → 打开示例 → 选择贪吃蛇）
3. 上传并执行
4. 玩一会儿
5. 停止 Job（2-3秒完成）
```

### 自定义开发

```
1. 输入需求（需求标签页）
2. 生成 Lua 或 生成并自动迭代
3. 在 Lua 标签页查看和编辑
4. 上传并执行
5. 在日志标签页查看结果
```

## 按钮功能

### Lua 标签页

- **上传并执行** - 运行编辑区的脚本
- **打开示例** - 选择并加载示例脚本
- **停止 Job** - 快速停止当前运行的脚本（2-3秒）
- **复制** - 复制脚本到剪贴板
- **粘贴** - 从剪贴板粘贴脚本

### 日志标签页

- **查询 job** - 查看当前 job 状态
- **完整日志** - 拉取设备端完整日志
- **停止 job** - 快速停止（与 Lua 标签页的功能相同）
- **清空** - 清空日志显示

## 故障排查

**问题：停止后仍显示 running**  
→ 脚本无 `lvgl.process_events()` 调用  
→ 设备会在 1.5s 后超时强制终止

**问题：执行感觉卡**  
→ 检查日志是否每秒更新  
→ 尝试断开重连设备

**问题：示例脚本加载失败**  
→ 确认已运行 `flutter pub get`  
→ 重新构建 APK
